# 在室カレンダー

部屋に誰がいつ居るかを、みんなで共有するためのシンプルなWebアプリです。
3〜4人程度の小さな部屋での利用を想定しています。LAN内の1台でサーバーを起動すれば、全員がブラウザから同じカレンダーを見て編集できます。

## 主な機能

- 月・週・日の表示切り替え（Googleカレンダー風。初期表示は月）
- 人ごとにアイコン画像と色を登録し、予定にアイコンを表示
- 上部の人アイコンをクリックすると、その人の予定を表示／非表示
- 同じ時間帯を複数の日にまとめて登録
  - 小さなカレンダーで日付をタップして選択
  - 曜日をタップすると、その月の同じ曜日をまとめて選択
  - PCの月表示では、日付をドラッグして範囲選択
- 週・日表示では、予定をドラッグして時間を移動、端を引っ張って長さを変更
- 日曜・祝日は赤、土曜は青で表示（祝日名も表示）
- スマホ対応（右下の「＋」ボタンで追加、月表示で日付をタップするとその日の表示へ）

## 必要なもの

- Node.js 22.13 以降（組み込みの `node:sqlite` を使います。動作確認は Node.js 26）

## 使い方

```sh
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開きます。
同じLAN内の他の端末からは `http://<サーバーのIPアドレス>:3000` でアクセスできます。

1. 右上の「＋ 人を追加」で、名前・色・アイコン画像（2MBまで）を登録します。画像を入れない場合は、名前の頭文字が色付きの丸で表示されます。
2. カレンダーの日付をクリックするか右下の「＋」を押して、在室時間を追加します。
3. 予定をクリックすると、編集・削除できます。

### 設定（環境変数）

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `3000` | 待ち受けるポート番号 |
| `DATA_DIR` | `./data` | データベースと画像の保存先 |

例: `PORT=8080 DATA_DIR=/srv/room-calendar npm start`

## データ

- データベース: `data/app.db`（SQLite）
- アイコン画像: `data/uploads/`

バックアップするときは `data/` フォルダごとコピーしてください。

## 構成

| 区分 | 使っているもの |
| --- | --- |
| フロントエンド | HTML / CSS / JavaScript（ビルド不要）、[FullCalendar](https://fullcalendar.io/) 6 |
| バックエンド | Node.js、Express、multer（画像アップロード） |
| データベース | SQLite（Node.js 組み込みの `node:sqlite`） |

```
server.js            API・画面ファイル・画像の配信
public/index.html    画面の骨組みとダイアログ
public/app.js        カレンダーと人の管理
public/holidays.js   日本の祝日の計算
public/style.css     見た目
```

### API

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/people` | 人の一覧 |
| POST | `/api/people` | 人を追加（multipart: `name`, `color`, `icon`） |
| PUT | `/api/people/:id` | 人を更新（`removeIcon=1` で画像を外す） |
| DELETE | `/api/people/:id` | 人を削除（その人の在室も削除） |
| GET | `/api/stays?start=&end=` | 期間内の在室一覧 |
| POST | `/api/stays` | 在室を1件追加 |
| POST | `/api/stays/batch` | 同じ時間で複数日に追加（`person_id`, `dates`, `startTime`, `endTime`, `note`） |
| PUT | `/api/stays/:id` | 在室を更新 |
| DELETE | `/api/stays/:id` | 在室を削除 |

## 注意事項

- ログイン機能はありません。LANにつながる人なら誰でも閲覧・編集できます。インターネットに公開しないでください。
- 他の人の変更は、ページを開き直すかタブに戻ったときに反映されます（自動更新はしません）。
- 1件の在室は1日の中で登録します。日付をまたぐ場合は日ごとに分けて登録してください。
- 祝日は現行の祝日法をもとに計算しています。法改正や特例の年には `public/holidays.js` の修正が必要です。
