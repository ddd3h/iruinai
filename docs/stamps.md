# スタンプ画像の用意

スタンプは、はじめから内蔵のイラスト（`public/reactions.js` の中の SVG）で動きます。`public/stamps/<id>.png` に画像を置くと、そのスタンプだけ画像に差し替わります。置いていないスタンプは内蔵のイラストのままです。サーバーの再起動は要りません（画面を再読み込みすると反映されます）。

## 画像の仕様

- 置き場所: `public/stamps/<id>.png`
- 形式: PNG、正方形、256×256 px、背景は透明
- 余白: 絵の周りに 8px ほどの余白を残す（吹き出しの中で 30px まで縮めて出るので、細い線は避ける）
- 絵柄: 太めの輪郭線、やわらかい色、丸い顔。LINE スタンプのような、文字を使わないもの
- 名前: 下の表の ID のとおり（大文字小文字も同じ）

| ID | 表示名 | 絵のイメージ |
| --- | --- | --- |
| `like` | いいね | にっこり笑う丸い顔。ほっぺが少し赤い |
| `angry` | おこ | 眉をつり上げて、むっとした顔。赤っぽい色 |
| `sad` | かなしい | 眉が下がって、涙が一粒。青っぽい色 |
| `thanks` | ありがとう | 目を閉じて微笑む顔。ほっぺにハート。ピンク |
| `otsu` | おつかれ | ほっとして力が抜けた顔。汗が一粒。やわらかい緑 |
| `laugh` | わらい | 目を細めて、口を大きく開けて笑う顔。オレンジ |

## 画像生成に渡す指示文（Codex など）

全体の指示（6枚とも同じ文を先頭に付ける）:

> チャットアプリのスタンプ用の、丸い顔のキャラクターを描いてください。正方形 256×256 px の PNG で、背景は透明にします。太めのやわらかい輪郭線、やさしいパステル調の色、シンプルな形で、文字は入れません。絵の周りに 8px ほどの余白を残し、小さく縮めても表情が分かるようにします。6枚で同じ絵柄・同じ線の太さにそろえます。

個別の指示:

- `like.png`: 黄色い丸い顔が、目を弧の形にして、にっこり笑っています。ほっぺが少し赤いです。
- `angry.png`: 赤っぽい丸い顔が、眉をつり上げて、口をへの字にして怒っています。
- `sad.png`: 青っぽい丸い顔が、眉を下げて、口を下に曲げています。涙が一粒こぼれています。
- `thanks.png`: ピンクの丸い顔が、目を閉じて微笑んでいます。ほっぺが赤く、頭のそばに小さなハートが浮かんでいます。
- `otsu.png`: 淡い緑の丸い顔が、目を細めて、ほっとした表情をしています。額に汗が一粒あります。
- `laugh.png`: オレンジの丸い顔が、目を「> <」の形に細めて、口を大きく開けて笑っています。

## 差し替えたあとの確認

1. 画像を `public/stamps/` に置く。
2. ページを再読み込みして、予定を開き、スタンプの欄で画像が出ることを確かめる。
3. 画像が壊れているときや読めないときは、自動で内蔵のイラストに戻る。
